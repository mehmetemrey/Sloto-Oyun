# Sayısal Loto

Java Swing ile yazılmış sayısal loto oyunu. 1-49 arasındaki sayılardan 6 tanesi seçilerek ve bahis tutarı girilerek oynanır.

## Özellikler
- 1-49 arasındaki butonlara tıklayarak numara seçme
- Rastgele numara seçme
- Çekiliş sonucunda kazanan ve eşleşen numaraların renklendirilmesi
- Bahis miktarına göre kazanç hesabı

## Çalıştırma
Projeyi IntelliJ IDEA, Eclipse veya NetBeans ile açıp `SayisalLoto.java` dosyasını doğrudan çalıştırabilirsiniz.

Veya terminalden Maven ile:

```bash
mvn clean package
java -jar target/SayisalLoto-1.0-SNAPSHOT.jar
```
